# contextlab dashboard

The browser dashboard for [contextlab](../README.md) — a React + TypeScript + Vite app served by the contextlab proxy at `/_contextlab/app/`.

```sh
npm ci
npm run build     # production build -> dist/, served by the proxy
npm run dev       # dev server with HMR, proxies data to the proxy on :8484
npm run lint      # oxlint
```

See the [root README](../README.md) for the full setup.
